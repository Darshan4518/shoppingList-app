# 🛒 ShoppingList

A simple and user-friendly Shopping List app built with **Kotlin** and **Jetpack Compose**. With this app, users can:

- 📝 Add products with names and quantities.
- ❌ Delete products easily.

## ✨ Features

- **Modern UI**: Clean and intuitive design using Jetpack Compose.
- **Add Products**: Quickly add product names and quantities.
- **Delete Products**: Remove items from the list with a single tap.

## ⚙️ Tech Stack

- **Kotlin**: The primary programming language.
- **Jetpack Compose**: For building declarative UIs.

## 🚀 Getting Started

Follow these steps to set up and run the project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Darshan4518/ShoppingList.git
   ```

2. **Open the project in Android Studio**.

3. **Build and run the app** on your Android device or emulator.
